# API platform

Create with `zel create my-api -t api-platform` using CLI and engine rc.10 or later.
Edit `content/site.yaml`, `content/pages.yaml` and `content/sections/`. Start with
the local guide. Run `zel view --watch` to build and preview using the hosted
renderer. Creation works offline; building needs the matching engine and a
supported container runtime. Serve the generated website over HTTP.

All product claims and prices are examples. No API, payment or signup service
is provided. The Kie theme follows kie.ai's visual language, with original
sample content and art. Previously published templates are unchanged.
