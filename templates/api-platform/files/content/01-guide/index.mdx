# Make it yours

This original API-platform starter pairs the Kie theme with a wide introduction,
pricing cards, an image carousel, a code example, feature tiles and an FAQ.
The sample product is fictional. Replace its plans, models and capabilities
with your own before publishing; this template does not implement an API.

## Edit the story

Change `content/site.yaml` for your name, theme and navigation. Edit the YAML
files in `content/sections/` for the home and Models pages, and reorder them in
`content/pages.yaml`. This guide is ordinary Markdown/MDX.

## Build and view

```sh
zel check --deep --strict
zel build
zel view --watch
```

Creation works offline. Build and validation download a verified renderer once;
later runs can use `--offline`. Double-click `site/index.html` after building and
keep the complete `site/` folder together when sharing it.

HTTP exports also use the renderer cache: `zel bs` creates an HTTP-served
edition, while `zel b` creates the rich double-click edition.

For Next.js development, run `zel dev --open`. It downloads a separate verified
development package, reuses private Node and wrapper sources under
`$ZELLIJ_HOME` (default `~/Dev/config/zellij`), and reloads valid edits. No installed
Docker, Node.js, npm or Python is needed. After the first successful run,
`zel dev --offline --open` uses those verified packages without downloading.
Ctrl-C stops the server and removes its temporary session; downloads remain.
`zel vw` is the lighter watched static preview.

Image commands and explicit `zel dev --dev-backend container` need a container
builder/runtime. This template does not configure PDF output.
