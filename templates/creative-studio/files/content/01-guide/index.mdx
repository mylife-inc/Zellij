# Make it yours

This studio uses the Porcelain theme, expressive serif headings and original geometric artwork. The home page introduces a practice; Selected work expands two fictional project studies. Begin with `content/sections/home/hero.yaml`, then replace the Field and Archive stories with your own work.

## Edit the story

Start with `content/site.yaml` for the name, theme and navigation controls.
`content/pages.yaml` orders the sections; each section is a separate, editable
YAML file in `content/sections/`. Add Markdown pages in this guide folder.
The sample identity and illustrations are fictional, not customer endorsements
or promises about a real product. Replace them with your own before publishing.

## Preview and publish

Run these commands from the folder containing `zel.yaml`:

```sh
zel check --strict
zel build
zel view --watch
```

These are rich website sections. `zel check`, `zel build` and `zel view --watch`
use the matching renderer downloaded and cached by `zel`; no separately installed
Docker, Node.js or Python is needed. After building, double-click `site/index.html`
and keep the complete `site/` folder together when sharing it. HTTP preview is
optional. Once the renderer is cached, add `--offline` to reuse it without a
network connection.

Creation itself works offline.

HTTP exports also use the renderer cache: `zel bs` creates an HTTP-served
edition, while `zel b` creates the rich double-click edition.

For Next.js development, run `zel dev --open`. It downloads a separate verified
development package, reuses private Node and wrapper sources under
`$ZELLIJ_HOME` (default `~/Dev/config/zellij`), and reloads valid edits. No installed
Docker, Node.js, npm or Python is needed. After the first successful run,
`zel dev --offline --open` uses those verified packages without downloading.
Ctrl-C stops the server and removes its temporary session; downloads remain.
`zel vw` is the lighter watched static preview.

Image commands and explicit `zel dev --dev-backend container` need a container
builder/runtime. This template does not configure PDF output.
