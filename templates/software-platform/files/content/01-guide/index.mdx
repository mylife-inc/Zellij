# Make it yours

This starter pairs a compact software introduction with a large interface showcase and a connected workflow. Begin with `content/sections/home/hero.yaml`, replace `content/assets/workspace.svg` with a real product capture, and turn the sample Workflow page into your own product tour.

## Edit the story

Start with `content/site.yaml` for the name, theme and navigation controls.
`content/pages.yaml` orders the sections; each section is a separate, editable
YAML file in `content/sections/`. Add Markdown pages in this guide folder.
The sample identity and illustrations are fictional, not customer endorsements
or promises about a real product. Replace them with your own before publishing.

## Preview and publish

Run these commands from the folder containing `zel.yaml`:

```sh
zel check --strict
zel build
zel view --watch
```

These are rich website sections. `zel check`, `zel build` and `zel view --watch`
use the matching renderer downloaded and cached by `zel`; no separately installed
Docker, Node.js or Python is needed. After building, double-click `site/index.html`
and keep the complete `site/` folder together when sharing it. HTTP preview is
optional. Once the renderer is cached, add `--offline` to reuse it without a
network connection.

Hosted `zel dev`, explicit `zel build --target static` and hosted deployment
commands retain their container requirements. Creation itself works offline.
This starter does not enable book PDF output.
