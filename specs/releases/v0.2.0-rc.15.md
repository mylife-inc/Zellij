# Zellij CLI 0.2.0-rc.15

Windows self-upgrade now recognizes WinGet portable installations. A managed
copy directs all `zel upgrade` requests to
`winget upgrade --id Shebka.Zel --exact` before contacting a release server or
changing files. Detection uses package identity and the actual installed file,
including custom folders and launcher links. Separate standalone copies keep
their existing upgrade behavior.

The release includes `zel-winget-v0.2.0-rc.15.zip`: native x64/ARM64 WinGet
manifests with pinned archive checksums, covered by `SHA256SUMS`. Manifest
publication is distinct from acceptance into Microsoft's public catalog.
Until catalog availability is announced, use the verified standalone installer,
Homebrew or the owned Scoop bucket.

`ZELLIJ_HOME` retains its resource/cache role. Package managers retain their
executable locations, and uninstall preserves the downloaded renderer cache.
Rich double-click build, check, watch and view continue to require only `zel`,
with a verified renderer downloaded on first use. Existing hosted/container/PDF
prerequisites are unchanged. This remains a pre-1.0 development candidate.
