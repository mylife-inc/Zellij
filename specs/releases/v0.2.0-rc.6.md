# Zellij CLI 0.2.0-rc.6

This candidate adds composable product sections and book publishing, including
optional build-time LuaLaTeX PDFs. Publication and acceptance status are recorded
separately; this file is the versioned release description.

- `zel presets` / `zel list presets` and `zel ns --preset` (`-p`) provide four
  reusable compositions. The engine adds bounded stack/grid/split composition,
  gradient reveal and media accordion, for 25 section types in total.
- Strict authoring checks expose discarded section fields. Corrected generated
  starters retain their explanatory text and section headings.
- A versioned `book` manifest owns title, authors, cover, front matter, parts,
  chapters and appendices. Portable web, reading order and publication JSON share
  one content revision; the Next adapter retains the same book structure.
- `zel build --pdf`, `zel pdf` / `zel export pdf` and native `pdf --check` add
  optional English/LTR classic print. Saved `pdf` settings choose enablement,
  A5/A4/Letter paper and 10/11/12pt type. `--no-pdf` overrides a saved choice.
- PDF-aware `view`/`dev` watch, static delivery and static images keep website,
  PDF and download links together. Failed/cancelled typesetting and changed
  inputs preserve the last complete export. Normal web builds remain native;
  the separate pinned LuaLaTeX toolchain stays out of runtime images.
- `book-classic@0.2.0` creates an editable publication with cover, preface, part,
  two chapters and appendix. PDF is off by default. Template catalogs disclose
  `print: lualatex`; creation validates that capability without executing it.
  Product templates remain at 0.1.0, and published older archives are immutable.

The new book starter is available with:

```sh
zel create my-book -t book-classic --name "My book" --set author="Your name"
zel build my-book
zel pdf my-book --check
zel build my-book --pdf
```

The last command requires a running Docker, Podman or nerdctl Linux runtime.
It never installs a runtime automatically. Advanced typography, multilingual/RTL
print, custom/technical/study templates, bibliography/index/glossary and semantic
numbered equations/theorems remain open. PDF-enabled Next images are explicitly
unsupported; use static images or disable PDF for web-only Next output.

This remains a development preview. Live provider/external-runner verification
and production-domain migration remain deferred; regression and artifact
acceptance do not establish that no undiscovered bugs exist.
