# Zellij CLI 0.2.0-rc.18

Rich HTTP builds and previews now use the verified renderer already used for
double-click websites. `zel build --target static` and `zel view --target static`
need no separately installed Docker, Node.js, npm or Python. Both support
`--offline` after downloading the matching renderer once under `$ZELLIJ_HOME`
(default `~/Dev/config/zellij`). HTTP and file exports share the same download.

Static validation and validation watch also use the cache, including optional
validation after imports. JSON target identity, strict/deep findings, recovery
and converted-source retention are preserved. Static preview keeps hosted URLs,
deployment prefixes, search, maths/diagrams, no-JavaScript reading/navigation,
configured analytics and last-good output during invalid edits. File output
retains relative double-click navigation and omits analytics. The cached
renderer also corrects active sidebar highlighting for sites with a deployment
prefix, in both rich output modes.

Netlify, Cloudflare Pages, Vercel, GitHub Pages and S3 static deployment builds
now use the cached renderer before their existing native provider uploads.
Provider credentials/network access are still required. Generated web-only
workflows pinned to rc.18 or later omit Docker setup; older CLI pins keep their
original prerequisites. Image delivery and enabled PDF builds retain theirs.

The release does not replace container image builders, Next.js development,
editable wrapper extraction or PDF typesetting with cached toolchains. Those
are separate planned migrations. No live provider verification or WinGet
catalog acceptance is claimed here. Templates are unchanged.

This is a pre-1.0 development candidate, not a claim of zero undiscovered bugs.
The two historical browser timing findings remain open. See the
[HTTP implementation record](https://github.com/mylife-inc/Zellij/blob/main/specs/zellij-cached-http-export-2026-11-21.md)
and [readiness record](https://github.com/mylife-inc/Zellij/blob/main/specs/zellij-readiness-2026-11-21.md)
for acceptance and release status.
