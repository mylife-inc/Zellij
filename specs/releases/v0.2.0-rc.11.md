# Zellij CLI 0.2.0-rc.11

This candidate expands the section composer with layered layouts, reusable
content, product selectors and scroll stories. Publication and final downloaded
artifact acceptance are recorded separately.

## Changes since 0.2.0-rc.10

- Add video nodes with direct-file/provider playback, WebVTT captions and
  transcript links. Self-hosted video retains native controls without JavaScript;
  provider video loads only when requested. Nested grids and splits respond to
  their containing width, keeping narrow cards readable on a wide screen.
- Add image/video backdrops and nine named foreground positions. Mobile, print,
  reduced-motion and no-JavaScript layouts retain an ordinary reading order.
- Add plain-Markdown prose, icons, lists, quotes, code, semantic tables,
  disclosures, carousels and keyboard-operable image galleries.
- Add independent product selectors (segments or swatches) and feature explorers
  (tabs or lists), with keyboard navigation and complete no-JavaScript/print
  content. These switch authored panels; they do not implement a cart or form.
- Add bounded scroll stages and ordered story scenes. Supported wide layouts can
  pin content and scrub a silent direct-file video segment as the reader scrolls.
  Narrow/tall content, reduced motion, reader opt-out, media failures and print
  retain the reading layout and native media controls.
- Reuse eight built-in sections as inline composition children: feature grids,
  pricing, statistics, CTA banners, bento grids, timelines, teams and logo strips.
  Headings, containing-column layouts and frame ownership adapt to the parent.
  Recursive sections and embedding below layers or scroll stages are rejected.
- Add five editable presets: `product-selector`, `feature-explorer`, `scroll-story`,
  `product-overview` and `studio-profile`. `zel presets` now lists nine; for example,
  `zel ns -p product-overview --out content/sections/overview.yaml` creates YAML
  you can edit. All existing site/book template archives retain their identity.
- Keep native CLI schemas, `zel explain`, section creation and structured editing
  in sync with the engine. Format 1, three group levels and 128 composer nodes
  remain the bounds; existing compositions remain valid.
- Fix disclosure printing in WebKit, repeated Markdown footnote IDs, delayed
  gallery focus restoration, announcement-aware sticky offsets, team-link click
  areas, accessible statistics and print contrast. Copy controls appear only
  when usable; command text remains selectable without clipboard support.

See the [composition guide](https://github.com/mylife-inc/Zellij/blob/904b132d2aa3e98d82fe6ef7a2585519f1757c2a/examples/zellij-docs/content/03-sections/compose.mdx)
and [section authoring guide](https://github.com/mylife-inc/Zellij/blob/904b132d2aa3e98d82fe6ef7a2585519f1757c2a/examples/zellij-docs/content/02-cli/new.mdx).
These pinned guides describe the released rc.11 fields, editable presets,
reading fallbacks and explicit limitations.

## Compatibility and current limits

These composition features need the matching rc.11 CLI and hosted engine.
Portable Markdown sites do not render the hosted section catalog. Compositions
accept a bounded schema, not arbitrary HTML/CSS/scripts, executable MDX or every
possible animation. Reuse is inline content, not references to other section
files. Overlapping story scenes and audio synchronization remain unsupported.

GitHub withdrew the previously reported development-only picomatch advisory on
November 18. Fresh production and full repository audits report zero findings;
the temporary exception has been removed. No dependency or runtime change is
attributed to that withdrawal. The [dated record](https://github.com/mylife-inc/Zellij/blob/main/specs/zellij-picomatch-disposition-2026-11-17.md)
preserves the earlier finding and its closure.

Production-domain migration and live-provider verification remain deferred.
This is a preview, not stable 1.0 or a guarantee of undiscovered-bug absence.
