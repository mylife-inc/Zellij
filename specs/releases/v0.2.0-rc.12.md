# Zellij CLI 0.2.0-rc.12

Rich documentation can now be generated with only `zel` installed:

```sh
zel build docs/zellij
zel build docs/zellij --offline
```

The first build downloads and verifies a versioned renderer, then caches it
separately from the small CLI. Subsequent builds can run offline. The generated
`site/index.html` opens directly in a browser with rich sections, navigation,
search, themes, local fonts and diagrams. No separately installed Docker,
Node.js, npm or Python is required. Keep the entire generated folder together.

Hosted sites now default to the `file` target. Use `--target static` explicitly
for the existing container-based Next HTTP export. Development, images and PDF
typesetting keep their documented prerequisites; portable Markdown stays native.
`zel doctor` in a rich site reports whether the renderer is cached.

The five rich website starters have new 0.1.1 versions with matching build and
offline instructions. Homebrew and Scoop messages distinguish rich builds from
commands that still use a container. Previously published template archives
retain their original bytes.

Archives and cached files are integrity-checked. Invalid content, corrupt
downloads and rendering failures preserve the previous site. External media
remain external, and custom Next application code requires an editable wrapper.
The rich engine renders trusted authored MDX with the user's local permissions.

This release also includes the recent shared rich file-export, responsive
navigation, theme preview and heading-update fixes. The candidate remains
pre-1.0; deferred live provider verification is unchanged.
