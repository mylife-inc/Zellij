# Zellij CLI 0.2.0-rc.8

This candidate adds technical/study book starters and downloadable PDFs in
Next.js book images. Publication and acceptance status are recorded separately;
this file is the versioned release description.

## Changes since 0.2.0-rc.7

- `book-technical@0.1.0` and `book-study@0.1.0` join the template catalog.
  They provide coordinated web/print layouts for mathematics and proofs, or
  passages and commentary, with citations, glossary and index examples.
- Shared `book.edition` selection coordinates native HTML, adapted Next and
  LuaLaTeX output. The three previously published template archives retain
  their versions and bytes. No fonts or runtime dependencies are added.
- PDF-enabled portable books now work with `zel ni`, saved `zel pub` and shared
  Next-image delivery. Web and print resolve from one publication snapshot;
  failed typesetting or changed input prevents image publication.
- Every reading page has a PDF download link that supports URL prefixes,
  keyboard activation and JavaScript-disabled readers. Only the verified
  finished PDF and receipt enter the serving image. TeX sources, logs, temporary
  files and the LaTeX toolchain stay out of that image.
- Generated GitHub, GitLab and CircleCI workflows support PDF-enabled Next
  images with CLI/engine rc.8 or later and reject older pins before writing.
- Public release acceptance installs the checksum-verified CLI and pulls the
  exact engine tag on native Linux amd64/arm64, then checks real PDF downloads,
  receipt consistency, layouts, private-file exclusion and failure preservation.

For supported book syntax and limits, see the [book guide](https://github.com/mylife-inc/Zellij/blob/9c61a2a59abc5843e4b0268e9ae0ef2a9020614a/examples/zellij-docs/content/02-cli/books.mdx).
Use the matching `0.2.0-rc.8` engine image for the new Next book features.
Portable web builds need no container runtime. PDF generation remains opt-in
and requires the supported isolated Linux toolchain through Docker, Podman or nerdctl.

## Compatibility and current limits

The three print editions support English/LTR books. Multilingual/RTL print,
additional print customization, BibTeX and arbitrary citation styles, per-row
equation numbering, rich glossary definitions, automatic indexing and deeper
index hierarchies remain open. Published template versions and archives are
immutable; existing created sites are never silently rewritten.

Separate intermittent WebKit overflow and documentation-readiness timeouts have
not reproduced in bounded follow-up checks and remain unexplained. Live provider
and external-runner verification and production-domain migration remain deferred.
This is a preview, with no claim that undiscovered bugs are impossible.
