## Optional cached PDF compiler

Generate supported book PDFs without installing Docker, Node.js, Python or TeX:

```sh
zel pdf my-book --pdf-backend cached
zel build my-book --pdf --pdf-backend cached
zel build my-book --pdf --pdf-backend cached --offline
```

The first use downloads the verified compiler (about 12 MB) and the rich
renderer/private Node if needed. Both are cached below `$ZELLIJ_HOME`, defaulting
to `~/Dev/config/zellij`. Later commands verify and reuse them; `--offline`
requires an intact cache. `ZEL_PDF_BACKEND=cached` also selects this backend for
PDF-enabled watched previews and builds. Existing output is retained on failure.

The container backend remains the default in rc.20. This candidate makes the
cached backend available explicitly; changing the default is a separate step
after public-package acceptance. Supported print content, fonts and languages
retain their documented boundaries. Arbitrary TeX packages are not downloaded.
Long URL-shaped link labels now wrap at punctuation, including bold/code labels,
while retaining their clickable destinations.

## Matching sources and verification

The optional PDF runtime and its complete corresponding-source archive are
separate release assets with per-file and combined SHA-256 checksums. Normal
PDF generation does not download the roughly 430 MB source archive. The adapter's
scoped GPL-2.0-only grant and original component notices accompany the assets;
the Rust CLI and website engine retain their existing terms. Sources and notices
must remain available with every offered compiler runtime.

The release gates compare package/source identities across six native targets,
replay the source verification independently, and build actual PDF and rich
website outputs offline with an empty PATH. Post-publication acceptance installs
the public CLI and verifies complete matching-source downloads from both release
repositories. Its run status is separate from pre-publication qualification.

The retained historical browser timing findings are not claimed fixed in this
candidate. Deferred provider verification and external package-catalog approval
remain separate.
