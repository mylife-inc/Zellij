# Zellij CLI 0.2.0-rc.10

This candidate adds customizable multilingual book printing and the Kie theme
with an API-platform starter. Publication and acceptance are recorded separately.

## Changes since 0.2.0-rc.9

- `pdf.style` controls accent color, body and cover/chapter-title fonts, chapter
  openings, line spacing and margins. Defaults preserve existing book designs;
  print-only styling does not change the manuscript revision.
- Print supports English, French, German and Spanish LTR and Arabic RTL.
  Pinned Amiri and Libertinus join the existing serif/sans choices. Arabic uses
  Amiri by default; math and code remain LTR. Fonts are embedded in the PDF.
  Regional language tags use the supported primary language; conflicting script
  declarations and unsupported print/font combinations fail before typesetting.
- Portable and Next book sites share the language/font settings and matching
  downloadable PDF receipts. PDF generation remains optional at build time and
  requires the supported Linux LuaLaTeX container runtime. Web-only books need
  no container runtime. Private TeX/font staging stays out of serving images.
- New fifteenth theme `kie` follows the inspected Kie palette, Space Grotesk
  typography, rounded cards and blue-light treatments in light and dark modes.
  The existing centered navigation, far-left optional company link, right-hand
  controls and two-level mobile drawer are preserved.
- `zel create my-api -t api-platform` creates the ninth starter: four routes,
  model cards, pricing, integration steps, FAQ and original local illustrations.
  This hosted website template requires the matching rc.10 engine and HTTP.
  All eight previously released template archives retain their versions/bytes.
- Correct shared scoped-theme selectors so presentation rules apply at theme
  roots while respecting nested boundaries. Feature/pricing card text now follows
  its own surface when the surrounding section has an accent/inverted background.
- Correct RTL skip-link positioning and update active Next.js pins to 16.4.6.
  Source acceptance covers all six native package targets, two browser engines,
  both Linux architectures, multilingual PDF layouts and website navigation.

## Compatibility and current limits

Book language support does not translate the web UI; its generated labels remain
English. Arabic code uses Amiri proportionally. Additional scripts, arbitrary
font paths and richer citation formats are separate work. The Kie reference's
public HTML/CSS was inspected, but Cloudflare blocked live browser comparison;
this is not a certified 100% pixel/behavior clone. The starter supplies original
content, without a model-service backend, authentication or billing.

Production hosting and live-provider verification remain deferred. This preview
is not a stable 1.0 release or a guarantee that undiscovered bugs are impossible.

## Post-publication dependency finding

On November 17, documentation CI identified an unpatched picomatch ReDoS
advisory in the repository build/test toolchain. Production dependencies and
a fresh all-features generated wrapper audit clean. The full repository audit
has seven development findings tracing to that advisory; a bounded disposition
expires December 1. This is an open upstream issue, not a resolved finding.
See [the scope and enforcement](../zellij-picomatch-disposition-2026-11-17.md).
Published rc.10 tags and assets remain unchanged.
