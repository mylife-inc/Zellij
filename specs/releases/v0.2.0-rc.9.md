# Zellij CLI 0.2.0-rc.9

This candidate adds three website starters and refines shared desktop/mobile
navigation. Publication and acceptance status are recorded separately; this
file is the versioned release description.

## Changes since 0.2.0-rc.8

- `product-launch@0.1.0`, `software-platform@0.1.0` and
  `creative-studio@0.1.0` join the eight-template catalog. Each includes two
  landing pages, two guide pages and original local artwork. They demonstrate
  product storytelling, software workflows and an editorial studio portfolio.
- Create a site with `zel create my-site -t product-launch` (or either other
  template name), edit its content, then run `zel build my-site`. The website
  starters use the hosted renderer and require a supported container runtime
  and the matching rc.9 engine. Published templates remain immutable; the five
  older archives retain their exact versions and bytes.
- Product identity and desktop menu now center on the viewport by default.
  The independent company mark stays at the far left; search/theme controls
  stay at the far right. `nav.align: left` remains available explicitly.
- The mobile hamburger opens large primary section names. A group opens its
  own titled view with Back and Close controls. Back restores menu scroll and
  focus; Close/Escape exit. Direct links navigate immediately, reopening starts
  at the main menu, and tablet drawers retain backdrop dismissal.
- Existing grouped headings, descriptions, icons, CTA/GitHub links and external
  new-tab settings are preserved. Reduced motion also applies when returning
  to the main menu. Closing a modal no longer shifts the underlying page.
- Bento foregrounds follow their tile surface; Porcelain muted text has improved
  light-theme contrast in hosted and portable output. No fonts or runtime
  dependencies are added.
- Release acceptance exercises the actual downloaded CLI and exact published
  engine on native Linux amd64/arm64: all new templates, light/dark and mobile/
  desktop layouts, no-JavaScript content, centered company/product navigation,
  section views, Back/Close and external new-tab links.

See the [template guide](https://github.com/mylife-inc/Zellij/blob/ab2377c21c076844dae38866bdfe125d9b4569d5/examples/zellij-docs/content/02-cli/templates.mdx)
and [navigation guide](https://github.com/mylife-inc/Zellij/blob/ab2377c21c076844dae38866bdfe125d9b4569d5/examples/zellij-docs/content/01-guide/menu.mdx).

## Compatibility and current limits

Portable books retain their separate sidebar. PDF generation remains opt-in.
Additional print customization, multilingual/RTL print, richer citation/index
features and additional installation channels remain separate work. Live-provider
verification and production-domain migration remain deferred. This is a preview;
passing acceptance is not a guarantee that undiscovered bugs are impossible.
