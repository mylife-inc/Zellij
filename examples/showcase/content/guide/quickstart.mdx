# Quickstart

This guide takes you from an empty account to a running workflow.

<Callout type="info">
You need Node.js 20.11 or newer. Check with `node --version`.
</Callout>

<Steps>
  <Step title="Install the CLI">
    The CLI drives setup and deployment.

    ```bash
    npm install -g @acme/cli
    ```
  </Step>

  <Step title="Authenticate">
    Sign in once; the token is cached in your home directory.

    ```bash
    acme login
    ```
  </Step>

  <Step title="Create your first workflow">
    Scaffold a workflow from the approval template.

    ```bash title="terminal"
    acme workflow create --template approval --name "Invoice review"
    ```
  </Step>

  <Step title="Run it">
    Trigger the workflow and watch it move through its steps.

    ```bash
    acme workflow run "Invoice review"
    ```
  </Step>
</Steps>

## Verifying the run

<Tabs>
  <Tab label="CLI">
    ```bash
    acme workflow status "Invoice review"
    ```
  </Tab>
  <Tab label="Dashboard">
    Open the dashboard and select **Workflows → Invoice review**. The run appears
    at the top of the activity list.
  </Tab>
</Tabs>

<Callout type="tip">
Workflows are versioned. Editing one creates a new version; in-flight runs finish
on the version they started with.
</Callout>
