**One shared passphrase, held by the Portal, which also does the building.
GitHub triggers and reports; it never decrypts.**

The same isolation as [RB](/quickstart/rb), with the simpler encryption
mode.

<Callout type="warning" title="This lab needs a Portal">
The Portal is a service you run — locally with `seal up`, or deployed. It is
the piece that holds key material on your behalf, so unlike the first four labs
there is infrastructure to stand up before anything works.

```bash title="terminal"
seal up          # the whole stack, locally
seal help        # deploying it somewhere
```

If you are evaluating CodeSeal, start with [RD](/quickstart/rd) instead — it
needs nothing but `sgit`.
</Callout>

## 1 · Seal the repository

Passphrase mode does not invent your secret — you pick it:

```bash title="terminal"
export SGIT_KEY="$(openssl rand -base64 32)"
```

```bash title="terminal"
sgit init --mode passphrase --ci-mode portal-build
```

**On your disk:**

```text title="$CODESEAL/<project>/"
passphrase      # a copy of $SGIT_KEY, so it outlives the shell
```

Every key is outside the repository, at `0600`. A key in the working tree is
one `git add -A` from being published.

## 2 · Tell GitHub

```bash title="terminal"
sgit auth
sgit ci provision
sgit ci verify
```

`CODESEAL_TOKEN` — authorises asking the Portal for a build, and nothing else.

## 3 · Protect something

```bash title="terminal"
sgit add-sensitive src/private
sgit encrypt
```

## 4 · The everyday loop

```bash title="terminal"
sgit add -s src/private/payment.rs
sgit commit -- -m "protect payments"
sgit push origin main
```

Push, and the workflow posts the commit SHA. A Portal worker clones, decrypts
with the stored passphrase, builds in an isolated workspace, and scrubs it.

## What you end up with

| | |
| --- | --- |
| On GitHub | ciphertext, and a token that only asks for builds |
| In the Portal | the passphrase, and the only machine that sees plaintext |
| Adding a teammate | tell them the passphrase |
| Removing one | rotate everything, and re-provision the Portal |
| To start a build | nothing — GitHub triggers, the Portal builds |
