## zigzag

Alternating text and image rows. The standard way to explain three or four
things in sequence without a wall of prose.

<SectionPreview example="zigzag" />

`body` accepts inline markdown — bold, italic, code spans and links. Not block
markdown: for that, use `markdown-prose` or a guide page.

## markdown-prose

The escape hatch. Free-form prose inside marketing styling, for the page that
needs a paragraph the tiles do not cover.

<SectionPreview example="markdown-prose" />

A `.md` or `.mdx` file under `sections/` is this type without saying so:

```mdx title="sections/home/story.md"
---
background: tinted
---

## Why we build Acme

Operations teams deserve better than a spreadsheet with opinions.
```

<Callout type="tip" title="Reach for this last">
If a page needs a lot of `markdown-prose`, it probably wants to be a guide page
instead — that layout has a sidebar, an on-this-page rail and search, and prose
is what it is for.
</Callout>

## timeline

A dated sequence: company history, a roadmap, milestones, the chapters of a
book. Rendered as an ordered list, because that is what it is.

<SectionPreview example="timeline" />

`date` is free text, not a date type — `1984`, `Q3`, `Chapter one` and
`Some time in the eighties` all belong. A bare year is accepted and
stringified, since YAML hands `2019` over as a number.

Items reveal from the side under `subtle` and `expressive`, which reads as the
sequence assembling itself as you scroll.

## faq

An accordion of question and answer pairs.

<SectionPreview example="faq" />

Built on `<details>`, so it expands and collapses with no JavaScript at all and
is keyboard operable for free. Answers accept inline markdown.
