# Optional PDF toolchain — original notices

This directory is a **private qualification artifact**, not a released toolchain.
It changes no third-party license and does not declare redistribution review
complete. The installed zel CLI does not download or use it.

NOTICES.json maps every collected notice to its original upstream path, source
archive and exact bytes. The licenses directory preserves those bytes unchanged;
identical notices may share a hash-named file. Package licence identifiers are
original catalogue metadata, not a replacement for the original terms.

The originals/ec directory contains every file listed by the original EC
00files.txt, including the manifest, copyright notice, documentation and font
sources. No file is renamed or modified within that complete distribution.
The runtime's generated font database and OpenType-only map are separate from
these original files.

The matching experimental-pdf-sources.tar.gz contains the complete pinned package
archives, the engine's corresponding-source archive, provenance metadata, build
recipes and these notices. It is a separate maintainer/source download, not an
additional installed rendering dependency. A release must provide the actual
matching source download alongside the optional runtime and retain the original
component terms. A filename in this document is not a published source offer.

The selected URL component is the unchanged 3.3 original from TeX Live 2012 final
(revision 16864). Its source and documentation both identify the LPPL without a
version number. originals/url retains all four original component files. The
later 3.4 component with ambiguous version wording is not included; its earlier
qualification history is preserved in the project audit records. This selection
does not edit an original notice or claim to clarify the later release's terms.
NOTICES.json records the outstanding final distribution review. Completing this
directory does not finish CLI integration or public-package acceptance.
